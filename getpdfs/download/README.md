This directory contains scripts for downloading PDF files into the directory pdfs/

==> odois.txt, otitle.txt, opmid.txt, olink.txt, odirect.txt <==
List of URLs to download

==> getpdfs.py <==
Download from URLs in odois.txt, otitle.txt, and opmid.txt

==> getpubmed.sh <==
Download from URLs in opmid.txt
